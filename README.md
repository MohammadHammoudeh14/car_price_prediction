# 🧠 Car Price Prediction using Linear & Lasso Regression

## 📋 Overview
This project applies **supervised machine learning** techniques to predict car selling prices using **Linear Regression** and **Lasso Regression** models.  
It includes **data preprocessing**, **model evaluation**, and **hyperparameter tuning** to improve Lasso performance.

---

## 🧰 Technologies Used
- Python  
- Pandas, NumPy  
- Scikit-learn  
- Matplotlib / Seaborn  
- Jupyter Notebook  

---

## ⚙️ Model Workflow
1. Load and clean the dataset  
2. Perform exploratory data analysis (EDA)  
3. Split data into training and testing sets  
4. Train **Linear Regression** and **Lasso Regression** models  
5. Tune Lasso hyperparameters using **GridSearchCV**  
6. Compare model performance using evaluation metrics  

---

## 📊 Dataset
The dataset includes car features such as year, selling price, fuel type, transmission, and owner type.  
**Source:** [Kaggle Car Dataset](https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho?resource=download&select=car+data.csv)

---

## 📈 Results
- **Linear Regression:** baseline model  
- **Lasso Regression (after tuning):** improved accuracy and reduced overfitting
