📋 Overview
This project applies supervised machine learning techniques to predict target values using Linear Regression and Lasso Regression models.
It includes data preprocessing, model evaluation, and hyperparameter tuning to improve Lasso performance.

🧰 Technologies Used
Python
Pandas, NumPy
Scikit-learn
Matplotlib / Seaborn
Jupyter Notebook

⚙️ Model Workflow
Load and clean the dataset
Perform exploratory data analysis (EDA)
Split data into training and testing sets
Train Linear Regression and Lasso Regression models
Tune Lasso hyperparameters using GridSearchCV
Compare model performance using evaluation metrics

📊 Dataset
The dataset includes car features such as year, selling price, fuel type, transmission, and owner type.
Source: https://www.kaggle.com/datasets/nehalbirla/vehicle-dataset-from-cardekho?resource=download&select=car+data.csv

📈 Results
Linear Regression: baseline model
Lasso Regression (after tuning): improved accuracy and reduced overfitting
